Zapret Domain Unlocker - Финальная инструкция
📌 Описание
Расширение Chrome для разблокировки доменов с локальным сервером.

📁 ВСЕ ФАЙЛЫ (6 основных)
text

├── server.py                    ← Сервер Python (порт 5000)
├── start_server.vbs            ← Скрытый запуск сервера
└── chrome-extension\
    ├── manifest.json           ← Настройки расширения
    ├── popup.html             ← Окно кнопки
    ├── popup.js               ← Логика работы
    ├── background.js          ← Контекстное меню
    └── Icons\                  ← Иконки
        ├── Icons16.png        ← 16x16

🚀 УСТАНОВКА ЗА 2 МИНУТЫ
Шаг 1️⃣: Запусти сервер
Вариант A (видимый):

cmd
cd C:\Zapret
python server.py
Увидишь окно с логами

Вариант B (скрытый):
Дважды кликни на start_server.vbs
Сервер запустится в фоне

Шаг 2️⃣: Проверь сервер
cmd
# Проверь что процесс есть
tasklist | findstr python

# Проверь что порт работает
netstat -ano | findstr :5000
✅ Должно быть: python.exe и порт :5000

Шаг 3️⃣: Установи расширение
Открой Chrome → chrome://extensions/

Включи "Режим разработчика" (правый верх)

Нажми "Загрузить распакованное расширение"

Выбери папку C:\Zapret\chrome-extension

✅ Готово! Иконка появится рядом с адресной строкой.

🎯 КАК ПОЛЬЗОВАТЬСЯ
Способ 1: Кнопка (основной)
Зайди на любой сайт

Нажми на иконку 🔓 в браузере

Нажми "Разблокировать этот сайт"

Способ 2: Правый клик (быстрый)
На любой странице → Правый клик → "🔓 Разблокировать этот сайт"

Способ 3: Горячая клавиша (для гиков)
Ctrl + Shift + U на любом сайте

⚙️ АВТОЗАПУСК ПРИ ВКЛЮЧЕНИИ КОМПЬЮТЕРА
Простой способ:
Нажми Win + R

Введи shell:startup

Создай ярлык для C:\Zapret\start_server.vbs

Теперь сервер будет запускаться автоматически при входе в Windows.

🛠️ РЕШЕНИЕ ПРОБЛЕМ
❌ "Сервер не запущен"
cmd
# 1. Запусти вручную чтобы увидеть ошибки
cd C:\Zapret
python server.py

# 2. Проверь Python
python --version

# 3. Если не установлен:
#    Скачай с python.org → Установи → Отметь "Add Python to PATH"

Проверь права на запись

Перезапусти сервер

❌ "Расширение не работает"
Перезагрузи расширение: chrome://extensions/ → 🔄

Нажми F12 в popup → Console → смотри ошибки

Проверь что сервер запущен

🔄 ПЕРЕЗАПУСК ВСЕГО
cmd
# 1. Останови сервер
taskkill /f /im python.exe

# 2. Перезапусти Chrome
# 3. Запусти сервер снова
wscript "C:\Zapret\start_server.vbs"
Или просто перезагрузи компьютер.
